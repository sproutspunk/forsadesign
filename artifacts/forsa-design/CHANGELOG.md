# Changelog

All notable changes to the Forsa Design public site and API Worker are documented in this file.

## [0.1.1] - 2026-09-04

### Changed

- Worker `verifyTurnstile` now emits structured logs (`event: turnstile_verify_failed`) with Cloudflare error codes, hostname, action, and token length when verification fails.

### Fixed

- Diagnosed live Turnstile failure: the deployed Worker's `TURNSTILE_SECRET_KEY` secret is returning `invalid-input-secret` from Cloudflare, which means the secret stored on the Worker does not match the active Turnstile widget. The key used when running `pnpm run test:secrets` locally is valid, but a different/wrong value is deployed. Fix by updating the Worker secret with the correct Turnstile secret key (see README).

## [0.1.0] - 2026-04-09

### Security

- Added Cloudflare Turnstile verification to `ContactForm`, `QuoteRequestForm`, `LeadMagnetForm`, `WaitlistForm`, and the quote calculator email flow.
- Hardened Worker CORS with an explicit origin allow-list.
- Added server-side `_gotcha` honeypot checks to `/api/contact`, `/api/lead-magnet`, `/api/waitlist`, and `/api/quotes/email`.
- Added invisible front-end honeypot fields to all public forms.

### Changed

- Stripped verbose AI-style comments and block dividers from `consentManager.ts` and the Worker cron handler.
- `consentManager.ts` now exports a minimal, comment-light API.

### Added

- Worker test suite (`forsa-api-worker/test/index.test.ts`) covering CORS, honeypot, Turnstile, Resend, rate limiting, and all public endpoints.
- Worker secrets diagnostic script (`scripts/test-secrets.mjs`) to validate real `TURNSTILE_SECRET_KEY` and `RESEND_API_KEY` before deployment.

### Fixed

- Ensured `public/audit-checklist.pdf` is generated by `generate:audit-checklist-pdf`.

## [0.0.0] - 2025

### Added

- Initial Forsa Design marketing site and quote calculator.
- Cloudflare Worker contact and quote-email endpoints.
