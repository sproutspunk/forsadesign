## 🔴 Problem 1: 317 KB nieużywanego JS (największy winowajca)

**Co widać w raporcie:**
```
Nieużywany JavaScript: 317,2 KiB (można zaoszczędzić 159,5 KiB)
- React DOM
- framer-motion  
- @floating-ui
- @radix-ui (toast, tooltip)
```

**Dlaczego to zabija:** Twoja strona to **statyczna wizytówka** (tekst + zdjęcie + 3 sekcje), a ładuje **cały stos Reacta** (103 KB + vendor). To jak wozić cegły Ferrari. Ten JS blokuje główny wątek i opóźnia interaktywność.

**Rozwiązanie — usuń framework:**

```html
<!-- ZASTĄP obecny <script src="/assets/index-...js"> czystym vanilla JS: -->

<script>
  // Cookie banner (jeśli masz)
  document.addEventListener('DOMContentLoaded', function() {
    const banner = document.getElementById('cookie-banner');
    const accept = document.getElementById('cookie-accept');
    if (banner && accept) {
      accept.addEventListener('click', function() {
        banner.style.display = 'none';
        localStorage.setItem('cookies', '1');
      });
      if (localStorage.getItem('cookies')) banner.style.display = 'none';
    }
  });
</script>
```

**Jeśli używasz Vite/React do builda:**
- Przełącz się na **czysty Vite bez Reacta** (vanilla JS + Tailwind) lub **Astro**
- Albo użyj `rollup-plugin-visualizer` i wywal framer-motion, radix-ui, floating-ui z `package.json` — to nie jest potrzebne na stronie wizytówce

**Efekt:** Spadek z 317 KB JS do ~2 KB. TBT spadnie z 70 ms do ~15 ms. Performance skoczy o 5-8 pkt.

## 🟠 Problem 2: LCP 3,3 s (CSS 19,6 KB + Google Fonts 750 ms + logo)

**Co widać w raporcie:**
```
LCP: 3,3 s
/index-Uwf2QtLB.css — 19,6 KiB, 940 ms (na critical path)
Google Fonts CSS — 750 ms
Logo: 160×132 wyświetlane jako 93×77 — można zaoszczędzić 5,8 KiB
```

### Fix A: Inline critical CSS

Z 19,6 KB CSS wydziel **critical CSS** (tylko to, co potrzebne do pierwszego ekranu — ~3-4 KB) i wklej inline w `<head>`:

```html
<head>
  <style>
    /* Tylko critical: reset, typografia, hero, nav, cookie banner */
    :root{--bg:#0a0a0f;--text:#e2e2e8;--accent:#d4a017}
    *,*::before,*::after{box-sizing:border-box;margin:0}
    html{font-family:Inter,system-ui,sans-serif;background:var(--bg);color:var(--text)}
    /* ... reszta critical CSS ~3KB ... */
  </style>
  
  <!-- Reszta CSS ładuj asynchronicznie: -->
  <link rel="preload" href="/assets/index-Uwf2QtLB.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
  <noscript><link rel="stylesheet" href="/assets/index-Uwf2QtLB.css"></noscript>
</head>
```

### Fix B: Self-host fonty (najszybsze) lub preload

**Opcja 1 — self-host (najlepsza):**
Pobierz woff2 z Google Fonts, wrzuć na `/fonts/` i usuń `<link>` do Google CDN. Eliminuje 750 ms z critical path.

**Opcja 2 — preload (szybsza niż obecnie):**
```html
<link rel="preload" href="https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTcviAwY.woff2" as="font" type="font/woff2" crossorigin>
```
Dodaj też `&display=swap` do URL Google Fonts, jeśli go nie masz.

### Fix C: Logo

```html
<!-- ZAMIAST: 160×132 wyświetlanego jako 93×77 -->
<img src="/logo-header.webp" width="160" height="132" ...>

<!-- DAJ: dokładny rozmiar ×2 dla retina -->
<img src="/logo-192x160.webp" width="96" height="80" alt="Forsa Design" loading="eager" decoding="async" style="width:93px;height:auto">
```

Wyeksportuj logo w WebP 192×160 (2× retina) — będzie ~2-3 KB zamiast 7 KB.

**Efekt:** LCP spadnie z 3,3 s do ~1,8-2,2 s. Performance +8-10 pkt.

## 🟡 Problem 3: CSP blokuje inline scripts (92/100 Best Practices)

**Co widać w raporcie:**
```
Błędy konsoli:
"Executing inline script violates CSP directive 'script-src 'self' ..."
```

Masz inline JS w HTML, ale CSP nie pozwala na `'unsafe-inline'`. 

**Rozwiązanie:** Dodaj hash do CSP lub przenieś JS do pliku.

**Opcja A — hash (szybsza):**
W Cloudflare (lub w nagłówku HTTP) zmień CSP:
```
script-src 'self' 'sha256-P+OA2SZOyoqLklwYG4WDnAyDpPI8jm48xQzM1739MTg=' 'sha256-PRLmPqen5VxALumR+j3G68vsTIGHsIDbJOcCiEe1TQM=' https://www.googletagmanager.com https://static.cloudflareinsights.com;
```

Hash musi pasować do Twojego inline scriptu. Możesz wygenerować:
```bash
echo -n 'TWOJ_INLINE_SCRIPT' | openssl dgst -sha256 -binary | openssl base64
```

**Opcja B — przenieś do pliku (czystsze):**
```html
<script src="/main.js" defer></script>
```
I usuń `'unsafe-inline'` z CSP.
