## 4. Podstrony — co zmienić

| URL | Obecny stan | Co zrobić |
|-----|-------------|-----------|
| `/en/` | Strona główna | Wkleić nowy hero + sekcje powyżej |
| `/pl/` | Strona główna PL | Wkleić nowy hero PL + sekcje |
| `/about` | Nie istnieje jako osobny HTML (SPA?) | Stworzyć statyczną podstronę `/en/about` z biogramem Miro |
| `/services` | Nie istnieje jako osobny HTML | Stworzyć statyczną podstronę `/en/services` z rozwinięciem usług |
| `/contact` | Nie istnieje jako osobny HTML | Stworzyć statyczną podstronę `/en/contact` z formularzem + danymi |
| `/en/terms` | OK | Dodać firmowe dane (company number, VAT) |
| `/en/privacy` | OK | Sprawdzić czy pasuje do nowego opisu |

**Kluczowe:** Każda podstrona musi mieć **własny, unikalny** `title`, `meta description`, `canonical` wskazujący na siebie, oraz `og:url` wskazujący na siebie. Obecnie wszystkie wskazują na `/en/` — to katastrofa SEO.

## 6. Robots.txt — co zrobić natychmiast

Twój obecny `robots.txt` blokuje wszystkie boty AI. Jeśli chcesz być widoczny w ChatGPT, Claude, Perplexity:

```text
User-agent: *
Allow: /
Disallow: /en/blog/
Disallow: /pl/blog/

Sitemap: https://forsadesign.co.uk/sitemap.xml
```

Usuń te linie:
```
User-agent: ClaudeBot → Disallow
User-agent: GPTBot → Disallow
User-agent: Google-Extended → Disallow
```

Albo — jeśli boisz się scrapowania treningowego — zostaw tylko:
```
User-agent: GPTBot
Allow: /

User-agent: ClaudeBot  
Allow: /

User-agent: Google-Extended
Allow: /
```

Ale blokowanie wszystkiego i jednocześnie płacenie za raport GEO to jak tankowanie dieslem do Tesli.

## Podsumowanie — co zrobić w tej kolejności:
