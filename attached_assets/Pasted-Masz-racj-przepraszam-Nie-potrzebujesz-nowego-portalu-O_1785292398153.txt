Masz rację — przepraszam. Nie potrzebujesz nowego portalu. Oto **konkretne zmiany do wprowadzenia w istniejącym kodzie**, punkt po punkcie.

---

## 1. ROBOTS.TXT — usuń blokady AI

**Obecnie masz (źle):**
```text
User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

User-agent: Google-Extended
Disallow: /
```

**Zamień na:**
```text
User-agent: *
Allow: /
Disallow: /en/blog/
Disallow: /pl/blog/

Sitemap: https://forsadesign.co.uk/sitemap.xml
```

Usuń wszystkie linie `Disallow: /` pod botami AI. Jeśli boisz się scrapowania treningowego, zostaw tylko `ai-train=no` w nagłówkach HTTP — ale nie blokuj dostępu.

---

## 2. HSTS — włącz w Cloudflare (nie w kodzie)

To nie jest zmiana w kodzie. Wejdź w panel Cloudflare:
- **SSL/TLS → Edge Certificates → HSTS**
- Włącz: **Enabled**
- max-age: **31536000** (1 rok)
- **Include subdomains: ON**
- **Preload: ON**
- Usuń ręczny nagłówek `Strict-Transport-Security: max-age=0` jeśli go wstrzykujesz w kodzie.

## 3. PODSSTRONY — unikalne canonical i treści

**Obecnie masz (źle):**
```html
<!-- na /about, /services, /contact -->
<link rel="canonical" href="https://forsadesign.co.uk/en/" />
```

**Zmień na:**

### /en/about/
```html
<title>About Miro — Industrial Web Developer | Forsa Design</title>

<link rel="canonical" href="https://forsadesign.co.uk/en/about/" />
```

## 5. BLOCKING SCRIPTS — dodaj defer

**Znajdź w kodzie:**
```html
<script src="..."></script>
```

**Zmień na:**
```html
<script src="..." defer></script>
```

Wszystkie skrypty, które nie są potrzebne do pierwszego renderu (analytics, cookies, etc.), muszą mieć `defer`. Jeśli masz inline JS w `<head>` — przenieś go przed zamykający `</body>`.

---

## 6. CSP — usuń unsafe-inline

**Obecnie masz (źle):**
```text
script-src 'self' 'unsafe-inline' https://...
style-src 'self' 'unsafe-inline' https://...
```

**Krok 1:** Przenieś cały inline JS do zewnętrznego pliku `main.js` i załaduj:
```html
<script src="/main.js" defer></script>
```

**Krok 2:** Przenieś inline CSS (jeśli masz w `<style>`) do `style.css` i załaduj:
```html
<link rel="stylesheet" href="/style.css">
```

**Krok 3:** Zmień CSP na:
```text
Content-Security-Policy: default-src 'self'; base-uri 'self'; object-src 'none'; frame-ancestors 'none'; img-src 'self' data: https://www.google-analytics.com https://www.googletagmanager.com; font-src 'self' https://fonts.gstatic.com; style-src 'self' https://fonts.googleapis.com; script-src 'self' https://www.googletagmanager.com https://static.cloudflareinsights.com; connect-src 'self' https://www.google-analytics.com https://analytics.google.com https://cloudflareinsights.com; form-action 'self';
```

**Usunięte:** `'unsafe-inline'` z `script-src` i `style-src`.

## 7. CACHE — dłuższy max-age dla assetów

**Obecnie:** `Cache-Control: public, max-age=3600` (1 godzina)

**Dla plików statycznych** (CSS, JS, obrazy) zmień na:
```
Cache-Control: public, max-age=31536000, immutable
```

W Cloudflare: **Caching → Configuration → Browser Cache TTL → 1 year** dla rozszerzeń `.css`, `.js`, `.webp`, `.png`, `.jpg`.

Dla HTML pozostaw krótszy cache (np. 1 godzina).

## 8. EXTERNAL LINKS — dodaj 2-3 outbound

W treści strony głównej lub w stopce dodaj:
```html
<p>Member of <a href="https://oeuk.org.uk" rel="noopener noreferrer">OEUK</a>. 
Based in <a href=\"https://www.aberdeenshire.gov.uk\" rel=\"noopener noreferrer\">Aberdeenshire</a>, Scotland.</p>
```

To buduje E-E-A-T i daje sygnał lokalizacyjny.
