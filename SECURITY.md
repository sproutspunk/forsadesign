Security Policy
Supported Versions

Security fixes will be applied to the actively maintained default branch of this repository.
Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, report it privately through the GitHub security advisory flow or contact the repository maintainers directly.

Please include:

    a description of the vulnerability,
    affected files or components,
    steps to reproduce,
    any suggested mitigation.

What to Expect

We will review security reports as soon as possible and respond with next steps.

If the report is confirmed, we will work on a fix and coordinate disclosure appropriately.
